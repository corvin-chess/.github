# Governance

Corvin is maintained by the `corvin-chess` GitHub organization.

## Roles

- **Organization owners** hold final authority on product direction, repository access, domains, hosting accounts, and legal commitments. Maintainers with write access create repositories, push, open and merge pull requests, tag releases, and deploy or publish when the required CLIs are already authenticated. Paid accounts, payment details, and store developer accounts remain owner-only.
- **Maintainers** review and merge pull requests in repositories where they have write access, enforce the Code of Conduct, and keep architecture decisions coherent.
- **Contributors** propose changes through issues and pull requests under [CONTRIBUTING.md](CONTRIBUTING.md).

## Decision records

Technical decisions that change architecture, protocol, licensing, security boundaries, or repository layout are recorded as Architecture Decision Records (ADRs). Accepted ADRs are the default unless a newer ADR supersedes them.

## Non-negotiable product principles

These principles are not open to contribution that would reverse them:

1. Online play against real people comes first.
2. Everything chess-specific is original to Corvin (rules library, engine, networks, pieces, boards, sounds).
3. Free forever: no ads, no paywall, no premium tier, no trackers.
4. Privacy by design and accessibility as release blockers.

Funding and sponsorship may be added by owners without introducing paywalled features or selling personal data.

## Conduct and security

Community behavior follows [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Vulnerability handling follows [SECURITY.md](SECURITY.md).

## Changes to this document

Material governance changes require an organization owner decision and a pull request to this repository.
