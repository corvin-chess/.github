Corvin is a free, open source chess platform for playing complete rated and casual games against real opponents, with unlimited analysis, our own engine and our own neural network. No ads, no paywall, no trackers.

<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=REPOSITORIES" alt="Repositories" /></p>

| Repository | Role |
|---|---|
| [web](https://github.com/corvin-chess/web) | Play site: board, lobby, games, analysis screen |
| [server](https://github.com/corvin-chess/server) | Real-time game server, lobby, tournaments, HTTP API |
| [chess-core](https://github.com/corvin-chess/chess-core) | Rules library with WASM and TypeScript bindings |
| [engine](https://github.com/corvin-chess/engine) | Corvin engine, UCI, native and WASM builds |
| [engine-train](https://github.com/corvin-chess/engine-train) | Self-play data, NNUE training, SPRT testing |
| [worker](https://github.com/corvin-chess/worker) | Volunteer client for distributed game analysis |
| [fairplay](https://github.com/corvin-chess/fairplay) | Fair play detection and review tooling |
| [puzzles](https://github.com/corvin-chess/puzzles) | Puzzle generation and verification from Corvin games |
| [explorer](https://github.com/corvin-chess/explorer) | Opening explorer built from Corvin games |
| [broadcast](https://github.com/corvin-chess/broadcast) | Live relay of over-the-board games |
| [design-system](https://github.com/corvin-chess/design-system) | Tokens, components, board and piece rendering |
| [assets](https://github.com/corvin-chess/assets) | Original pieces, boards, sounds and brand files |
| [mobile](https://github.com/corvin-chess/mobile) | Android and iOS app |
| [sdk](https://github.com/corvin-chess/sdk) | Official API clients |
| [bots](https://github.com/corvin-chess/bots) | Connect engines as bot accounts |
| [translations](https://github.com/corvin-chess/translations) | Locale files and translation workflow |
| [infra](https://github.com/corvin-chess/infra) | Self-hosting, observability, backups, load tests |
| [website](https://github.com/corvin-chess/website) | Project site and docs (Astro + Starlight) |
| [.github](https://github.com/corvin-chess/.github) | Org profile, templates and shared workflows |

- Free forever: no ads, no paywall, no premium tier
- Everything chess-specific is ours: engine, network, pieces, boards, sounds
- Online play first: complete rated and casual games against real people
- Unlimited analysis for everyone
- Privacy by design: no trackers, minimal data, full export and deletion
- Accessible by default: keyboard and screen reader play
