# Support

## How to get help

- **Bugs and feature requests:** open an issue in the repository that owns the component, using the issue forms when they are offered.
- **Contribution process:** read [CONTRIBUTING.md](CONTRIBUTING.md).
- **Community standards:** read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Security vulnerabilities:** do not open a public issue; follow [SECURITY.md](SECURITY.md).

## What we cannot provide yet

Corvin repositories and the public docs site are still being bootstrapped. There is no guaranteed response SLA, live chat, or email help desk until the organization owner publishes support channels.

## Self-hosting and operations

Operational runbooks will live in the `infra` repository once it exists. Agents and contributors must not deploy production systems; deployment remains an owner action.

## Fair play and account actions

Appeals and moderation processes for the live service will be documented when those features ship. Do not expect account restoration through GitHub issues for a product that is not yet publicly deployed.
